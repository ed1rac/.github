## 🏛️ Sobre este Repositório

No ecossistema do GitHub, o repositório público especial `.github` atua como **Community Health Repository** da conta. Isso significa que as diretrizes, padrões de contribuição, código de conduta e modelos de issue/pull request aqui estabelecidos são automaticamente herdados por todos os repositórios públicos que não definam modelos específicos.

## 📂 Arquivos Globais Integrados

| Arquivo | Descrição |
|---|---|
| [`.github/CODE_OF_CONDUCT.md`](./.github/CODE_OF_CONDUCT.md) | **Código de Conduta**: Baseado no *Contributor Covenant v2.1*, estabelece um ambiente inclusivo, acolhedor e respeitoso para todos os participantes e estudantes. |
| [`.github/CONTRIBUTING.md`](./.github/CONTRIBUTING.md) | **Guia de Contribuição**: Instruções claras e didáticas sobre como abrir issues, propor correções, criar forks, formatar código e enviar Pull Requests. |
| [`.github/ISSUE_TEMPLATE/`](./.github/ISSUE_TEMPLATE/) | **Modelos de Issues**: Formulários padronizados para reporte de bugs e solicitações de novas funcionalidades ou materiais de aula. |
| [`.github/PULL_REQUEST_TEMPLATE.md`](./.github/PULL_REQUEST_TEMPLATE.md) | **Modelo de PR**: Checklist de qualidade para revisão de código, testes e documentação. |
| [`.github/SECURITY.md`](./.github/SECURITY.md) | **Política de Segurança**: Orientações sobre comunicação responsável de potenciais vulnerabilidades. |
| [`.github/FUNDING.yml`](./.github/FUNDING.yml) | **Configuração Global de Patrocínio**: Centralização do botão oficial "Sponsor" do GitHub para toda a conta. |
